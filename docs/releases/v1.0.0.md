## 🎯 개요

네트워크 장비 설정 파일에서 IP 정보를 파싱하여 웹 대시보드로 제공하는 초기 릴리즈입니다.

---

## 🔧 변경사항

### 추가
- **Nokia SR OS config 파싱**: System IP, Interface IP, Static Route 추출
- **웹 대시보드**: Bootstrap 5 기반 반응형 UI
- **Excel/CSV 내보내기**: 파싱된 IP 데이터 내보내기
- **Docker 지원**: Dockerfile, docker-compose.yml 포함
