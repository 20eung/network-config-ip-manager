# Release Notes - network-config-ip-manager v1.5.0-server

**릴리즈 날짜**: 2026-01-XX
**버전**: v1.5.0-server
**이전 버전**: v1.3.0
**릴리즈 타입**: Feature Release (server 브랜치)

---

## 🎯 개요

SK-Net Portal(NetDevOps Portal) 연동을 위한 server 브랜치 버전입니다.
standalone 버전(main 브랜치)에서 서버 연동 기능을 추가했습니다.

---

## 🔧 변경사항

### 추가
- **SK-Net Portal 통합**: iframe 임베드 및 portainer-network 연동
- **Authentik Forward Auth 지원**: SSO 인증 연동
- **서버 디렉토리 자동 로드**: `/data/configs/{cloud,isp,mpls}/` 자동 탐색
- **portainer-network 연동**: 포털 네트워크와 통합

### 변경
- standalone 버전 → main 브랜치로 분리
- server 버전 → server 브랜치로 별도 관리
